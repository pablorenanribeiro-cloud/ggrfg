# 📅 Minha Rotina Acessível

Este projeto é uma página web desenvolvida com **HTML5** e **CSS3** para apresentar uma rotina diária de maneira previsível, clara e organizada. 

A aplicação foi pensada especialmente para pessoas que necessitam de organização visual e previsibilidade em seu dia a dia (como pessoas neurodivergentes, no espectro autista ou TDAH), baseando-se na premissa fundamental: **O que fazer → Quando fazer → Onde fazer**.

## 🚀 Tecnologias Utilizadas
- HTML5 (Semântico)
- CSS3 (Flexbox, Grid, Variáveis CSS)
- GitHub Pages (Hospedagem)

## ♿ Práticas de Acessibilidade Adotadas
Durante o desenvolvimento da interface, as seguintes boas práticas de acessibilidade e UX foram implementadas:
1. **HTML Semântico:** Utilização de tags como `<header>`, `<nav>`, `<main>`, `<article>` e `<section>` para que leitores de tela interpretem corretamente o layout.
2. **Atributos ARIA:** Adição de `aria-label` nos botões e menus e `aria-labelledby` nas seções para fornecer contexto a tecnologias assistivas.
3. **Alto Contraste e Cores Suaves:** Evitamos cores gritantes que causam sobrecarga sensorial, utilizando contrastes adequados para facilitar a leitura.
4. **Foco Visível:** O estado `:focus-visible` no CSS garante que a navegação por teclado (Tab) seja clara, mostrando exatamente onde o usuário está interagindo na tela com um contorno laranja destacado.
5. **Comunicação Direta:** Textos simples, curtos e com instruções lógicas.

## 🧠 Reflexão sobre o Projeto
Desenvolver esta página demonstrou que acessibilidade na web vai muito além de leitores de tela. Envolve criar ambientes previsíveis. A divisão clara em "Cards" ajuda a diminuir a ansiedade e a sobrecarga cognitiva, tornando a interface não apenas bonita, mas funcional, inclusiva e psicologicamente amigável. A adição da área de "Dicas de Comunicação" incentiva a neurodiversidade, educando também as pessoas ao redor do usuário.
